## 5. 핵심 발견

### 발견 1: GenAI 증강의 포화점은 25~50장/클래스

- Cable: genai_50에서 정점 (+3.27)
- Screw: genai_25에서 정점 (+6.25)
- 50장 이후 성능 하락 또는 정체

### 발견 2: 클래스 수가 많으면 GenAI 효과 감소

```
1 클래스 (Cable, Screw):  GenAI 효과 ✅
2 클래스 (Casting, Wood): GenAI 효과 ❌/➖
4 클래스 (Console, Cylinder): GenAI 효과 ❌
```

클래스가 많을수록 GenAI 데이터의 클래스 간 불균형/품질 차이가 누적되어 전체 성능을 저하시킬 수 있음.

### 발견 3: FID와 실제 학습 효과의 괴리

FID 테스트에서 13개 클래스 전부 PASS(AI 이미지가 원본 분포에 가까움)였지만, 실제 학습에서는 Casting, Cylinder에서 GenAI가 역효과. **FID는 이미지 분포만 측정하며, 마스크 품질·도메인 갭은 반영하지 못함.**

### 발견 4: Cascade Mask R-CNN이 GenAI 데이터에 더 강건

- Cascade는 3-stage ROI Head로 점진적으로 bbox를 보정
- GenAI 데이터의 잡음(부정확한 마스크, 도메인 갭)에 덜 민감
- Cable, Screw에서 Cascade가 더 큰 개선폭을 보임

## 7. 한계 및 향후 과제

1. **1회 실행**: seed 1개만 사용. 3-seed 반복으로 통계적 신뢰도 확보 필요
2. **Casting 저성능 원인 분석**: GenAI 마스크 품질 시각 검증, 클래스별 AP 분해 필요
3. **Screw 성능 불안정**: 짝수 조건(50, 100)에서 하락하는 패턴 → seed 효과인지 확인 필요
4. **Pixel-level 평가**: Dice coefficient로 마스크 품질 정량 분석
5. **전통 증강과 비교 (exp2)**: GenAI vs 전통 증강 효과 비교 실험 미완
