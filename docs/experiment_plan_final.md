## 실험 1: GenAI 증강 수에 따른 성능 변화

### 목적
GenAI로 생성한 결함 이미지를 클래스당 0~125장까지 늘려가며 instance segmentation 성능 변화를 측정한다.

### 조건

| 조건 | 원본/cls | GenAI/cls | 전통/cls |
|------|:---:|:---:|:---:|
| baseline | 전체 | 0 | 0 |
| genai_25 | 전체 | 25 | 0 |
| genai_50 | 전체 | 50 | 0 |
| genai_75 | 전체 | 75 | 0 |
| genai_100 | 전체 | 100 | 0 |
| genai_125 | 전체 | 125 | 0 |

### 설정

| 항목 | 값 |
|------|-----|
| 모델 | Mask R-CNN, Cascade Mask R-CNN (2종) |
| 카테고리 | Cable, Screw, Casting, Console, Cylinder, Wood (6개) |
| 시드 | 42 (단일) |
| HP | lr=0.0015, batch=12, max_epochs=200, patience=10 |

### 학습 횟수
6조건 × 2모델 × 6카테고리 = **72회**

### 상태: **완료**

### 주요 결과

| 카테고리 | GenAI 효과 | 최적 조건 | baseline → 최고 AP |
|----------|:---------:|----------|:------------------:|
| Cable | ✅ | genai_50 (Cascade) | 42.44 → **45.71** (+3.27) |
| Screw | ✅ | genai_25 (Cascade) | 35.65 → **41.90** (+6.25) |
| Casting | ❌ 역효과 | baseline | 11.80 |
| Console | ➖ 무관 | baseline | 19.16 |
| Cylinder | ❌ 역효과 | baseline | 39.70 |
| Wood | ➖ 미미 | genai_100 | 24.72 → 24.98 (+0.26) |

### Unified 14클래스 통합 학습 결과 (클래스별 분해)

GenAI 증가 → AP 상승 패턴인 defect:

| defect | 카테고리 | baseline → genai_125 | 개선폭 |
|--------|---------|:-------------------:|:------:|
| Dirty | Console | 3.27 → **8.21** | +151% |
| Inclusoes | Casting | 3.92 → **8.92** | +128% |
| impurities | Wood | 14.82 → **15.91** | +7% |

## 실험 2: 전통 증강 vs GenAI + 최적 배율 탐색 + 7종 모델 비교

### 목적

1. 같은 양(125/cls)에서 **전통 증강 vs GenAI** 효과 비교
2. (원본 + GenAI)에 **전통 증강을 N배 추가**했을 때 최적 배율 탐색
3. 최적 배율에서 **7종 모델** 성능 비교

### 대상 카테고리

실험 1에서 GenAI 효과가 확인된 **3개 defect** 선정 (단일 클래스 학습):

| 후보 | 카테고리 | exp1 근거 | 비고 |
|------|---------|----------|------|
| Inclusoes | Casting | Unified +128% | 저성능 defect, GenAI ↑ → AP ↑ |
| Dirty | Console | Unified +151% | 저성능 defect, GenAI ↑ → AP ↑ |
| impurities | Wood | Unified +7% | 완만한 상승 |
| thunderbolt | Cable | 개별 +3.27 | 소량에서 효과 |
| defect | Screw | 개별 +6.25 | 소량에서 효과 |

→ 최종 3개 선정 후 진행

### 조건

#### Phase 1: cond1~3 (전통 vs GenAI 비교)

| 조건 | 원본/cls | GenAI/cls | 전통/cls | 의미 |
|------|:---:|:---:|:---:|------|
| cond1 | 20 | 0 | 0 | baseline |
| cond2 | 20 | 0 | 125 | 전통 증강만 |
| cond3 | 20 | 125 | 0 | GenAI만 |

**비교:**
- cond1 vs cond2: 전통 증강의 효과
- cond1 vs cond3: GenAI의 효과
- **cond2 vs cond3: 같은 125장에서 전통 vs GenAI 직접 비교**

**모델**: Mask R-CNN, Cascade Mask R-CNN (2종)

#### Phase 2: cond4 (최적 배율 + 7종 모델)

(원본 20 + GenAI 125) = 145장을 기반으로, 전통 증강을 1~10배 추가:

| N | 원본/cls | GenAI/cls | 전통/cls | 전통 = (20+125)×N | 총 데이터/cls |
|:-:|:---:|:---:|:---:|:---:|:---:|
| 1 | 20 | 125 | 145 | 145×1 | 290 |
| 2 | 20 | 125 | 290 | 145×2 | 435 |
| 3 | 20 | 125 | 435 | 145×3 | 580 |
| 4 | 20 | 125 | 580 | 145×4 | 725 |
| 5 | 20 | 125 | 725 | 145×5 | 870 |
| 6 | 20 | 125 | 870 | 145×6 | 1,015 |
| 7 | 20 | 125 | 1,015 | 145×7 | 1,160 |
| 8 | 20 | 125 | 1,160 | 145×8 | 1,305 |
| 9 | 20 | 125 | 1,305 | 145×9 | 1,450 |
| 10 | 20 | 125 | 1,450 | 145×10 | 1,595 |

**모델**: 7종 전부
- detectron2: Mask R-CNN, Cascade Mask R-CNN, MaskDINO, Mask2Former
- mmdet: Cascade R-CNN, SOLOv2, RTMDet-Ins

### 설정

| 항목 | 값 |
|------|-----|
| 시드 | 42 (단일) |
| lr | 0.0015 |
| batch_size | 12 |
| max_epochs | 200 |
| early_stopping_patience | 10 |
| eval_period_epochs | 5 |
| input_max_size | 1333 |
| GPU | A100 80GB × 3 (3명 분배) |

### 학습 횟수

| Phase | 조건 수 | 모델 수 | 카테고리 | 소계 |
|-------|:------:|:------:|:-------:|:----:|
| Phase 1 (cond1~3) | 3 | 2 | 3 | **18회** |
| Phase 2 (cond4 N=1~10) | 10 | 7 | 3 | **210회** |
| **합계** | | | | **228회** |

### 비교 구조 (전체 흐름)

```
[Phase 1] 전통 vs GenAI 비교

  cond1 (원본 20/cls)
     ├── vs cond2 (+ 전통 125)  → 전통 증강 효과
     └── vs cond3 (+ GenAI 125) → GenAI 효과
              cond2 vs cond3    → 전통 vs GenAI 직접 비교

[Phase 2] 최적 배율 탐색 + 7종 모델

  cond4 = (원본 20 + GenAI 125) + 전통 N배

     segm_AP
       ↑
       │      ╭──── 최적 N (포화점)
       │    ╱    ╲
       │  ╱        ╲── 과적합/포화
       │╱
       └──────────────→ N (1~10배)

  → 최적 N에서 7종 모델 성능 순위 확정
```
