## 1. 창업 아이템명: CarNerf

> AI 기반 차량 3D 복원 및 손상 분석 플랫폼

---

## 1-1. 창업아이템의 개발동기

### 문제 인식

- **자동차 사고 후 손상 평가의 비효율성**
  - 현재: 정비소 방문 → 육안 검사 → 수기 견적 (시간 소요, 주관적 판단)
  - 보험사 손해사정 과정에서 분쟁 빈번 (연간 약 ___건)

- **기존 2D 이미지 기반 손상 분석의 한계**
  - 평면 사진만으로는 손상 깊이, 면적 정확히 측정 불가
  - 촬영 각도에 따라 손상 정도 왜곡

- **NeRF(Neural Radiance Fields) 기술의 발전**
  - 스마트폰 촬영만으로 3D 복원 가능해진 기술적 배경
  - 차량 도메인 특화 적용 사례 부족 → **기회**

### 핵심 Pain Point

| 이해관계자 | 문제점 |
|-----------|--------|
| 차량 소유자 | 손상 정도를 객관적으로 파악 어려움, 수리비 과다 청구 우려 |
| 보험사 | 현장 출동 비용, 손해사정 인력 부족, 사기 탐지 어려움 |
| 정비소 | 견적 작성 시간 과다, 고객과의 신뢰 문제 |

## 2-1. 창업아이템의 개발방안

### 기술 구성

```
[스마트폰 촬영 (다각도 영상)]
        ↓
[NeRF 기반 3D 복원 엔진]
        ↓
[AI 손상 영역 검출 (Instance Segmentation)]
        ↓
[손상 분석 리포트 자동 생성]
        ↓
[수리비 자동 견적]
```

### 핵심 기술 스택

| 기술 | 용도 | 비고 |
|------|------|------|
| NeRF / 3D Gaussian Splatting | 차량 3D 복원 | 실시간 렌더링 |
| Instance Segmentation | 손상 부위 검출 | Mask R-CNN, MaskDINO 등 |
| Depth Estimation | 손상 깊이 측정 | 3D mesh 기반 |
| LLM | 리포트 자동 생성 | 자연어 손상 설명 |

### 개발 로드맵

| 단계 | 기간 | 내용 |
|------|------|------|
| Phase 1 | 2026.04 ~ 2026.06 | NeRF 차량 3D 복원 PoC |
| Phase 2 | 2026.07 ~ 2026.09 | 손상 검출 AI 모델 개발 |
| Phase 3 | 2026.10 ~ 2026.12 | 통합 앱 프로토타입 (MVP) |
| Phase 4 | 2027.01 ~ 2027.03 | 베타 테스트 및 고도화 |
