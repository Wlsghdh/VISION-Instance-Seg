### 2. 통합 학습 코드 구조 생성

기존 `training/maskdino/` 코드는 그대로 보존하고, 7종 모델 × 3종 카테고리 × 다양한 실험 조건을 통합 관리하는 새 코드를 작성함.

```
training/
├── __init__.py
├── config.py              ← 중앙 설정 (경로, 카테고리, 모델, 실험 정의)
├── data_pipeline.py       ← 데이터 병합 + 프레임워크별 등록
├── train.py               ← 통합 CLI 진입점
├── evaluate.py            ← 독립 평가 스크립트
├── adapters/
│   ├── __init__.py
│   ├── base.py            ← ModelAdapter ABC (setup/train/evaluate)
│   ├── detectron2_adapter.py  ← Mask R-CNN, Cascade Mask R-CNN, MaskDINO, Mask2Former
│   └── mmdet_adapter.py       ← Cascade R-CNN, SOLOv2, RTMDet-Ins
├── utils/
│   ├── __init__.py
│   ├── maskdino_mapper.py ← Polygon→BitMask 변환 (기존 train_full.py에서 추출)
│   └── report.py          ← 결과 CSV/비교 테이블 생성
├── maskdino/              ← 기존 코드 보존 (reference)
│   ├── train_original.py
│   ├── train_full.py
│   ├── evaluate.py
│   └── ...
└── train_template.py      ← 기존 템플릿 보존
```

### 3. 생성된 파일별 설명

#### `training/config.py` — 중앙 설정

- `PROJECT_ROOT`: `/home/jjh0709/gitrepo/VISION-Instance-Seg`
- **CATEGORIES** (3종):
  - `Cable` — thunderbolt 1클래스, val에서 break 필터링 + category_id 리매핑
  - `Screw` — defect 1클래스
  - `Casting` — Inclusoes + Rechupe 2클래스
- **MODELS** (7종):
  - detectron2: `mask_rcnn`, `cascade_mask_rcnn`, `maskdino`, `mask2former`
  - mmdet: `cascade_rcnn`, `solov2`, `rtmdet_ins`
- **EXPERIMENTS** (3종): exp1(GenAI양 변화), exp2(전통 vs GenAI 비교), exp3(7모델 비교)
- **DEFAULT_HYPERPARAMS**: max_iter=10000, lr=1e-4, batch_size=2, seed=42

#### `training/data_pipeline.py` — 데이터 준비

- `prepare_dataset(experiment, condition, category)` → 병합 데이터셋 생성
- `register_for_detectron2()` → DatasetCatalog 등록
- `prepare_val_dataset(category)` → Cable thunderbolt 필터링 포함
- `get_mmdet_data_config()` → mmdet용 config dict 반환
- CLI로 직접 실행 가능 (데이터 준비만)

#### `training/adapters/` — 모델 어댑터 패턴

- `base.py`: `ModelAdapter` ABC — `setup()`, `train()`, `evaluate()` 인터페이스
- `detectron2_adapter.py`: Mask R-CNN/Cascade Mask R-CNN은 model_zoo 사용, MaskDINO/Mask2Former는 외부 repo config 로드
- `mmdet_adapter.py`: mmengine Runner API 사용, iteration 기반 학습

#### `training/train.py` — 통합 CLI

- 모든 조합을 하나의 커맨드로 실행
- 학습 후 자동 평가
- 결과 `results/evaluation/results.json`에 누적 저장

#### `training/evaluate.py` — 독립 평가

- 이미 학습된 모델을 일괄 평가

#### `training/utils/report.py` — 리포트 생성

- CSV 내보내기, 조건×모델 비교 테이블 출력

### 4. 검증 결과

- 모든 프레임워크 import 정상 확인
- 데이터 파이프라인 테스트: `Cable exp2 cond1 → 25장 병합` 성공
- CLI `--help` 정상 출력

## 사용법 가이드

### 데이터 준비만 (학습 전 확인용)

```bash
cd /home/jjh0709/gitrepo/VISION-Instance-Seg

# Cable, exp2, cond1 데이터 병합
python -m training.data_pipeline --category Cable --experiment exp2 --condition cond1

# 전체 카테고리, exp2, 모든 조건
python -m training.data_pipeline --category all --experiment exp2 --condition all

# 강제 재생성 (기존 데이터 덮어쓰기)
python -m training.data_pipeline --category Cable --experiment exp2 --condition cond3 --force
```

출력 위치: `results/merged_datasets/{experiment}/{condition}/{category}/`

### 단일 모델 학습

```bash
# Mask R-CNN으로 Cable, exp2, cond1 학습
python -m training.train \
    --category Cable --experiment exp2 --condition cond1 \
    --model mask_rcnn

# MaskDINO로 Screw, exp2, cond3 학습 (하이퍼파라미터 커스텀)
python -m training.train \
    --category Screw --experiment exp2 --condition cond3 \
    --model maskdino --max-iter 15000 --lr 5e-5

# 빠른 테스트 (100 iteration만)
python -m training.train \
    --category Cable --experiment exp2 --condition cond1 \
    --model mask_rcnn --max-iter 100
```

### 전체 조건 실행

```bash
# Cable에서 exp2 전체 조건을 MaskDINO로 학습
python -m training.train \
    --category Cable --experiment exp2 --condition all \
    --model maskdino

# exp3: 7모델 비교 (Cable, original_only)
python -m training.train \
    --category Cable --experiment exp3 --condition original_only \
    --model all
```

### 평가만 (이미 학습된 모델)

```bash
# 특정 모델 평가
python -m training.train \
    --category Cable --experiment exp2 --condition cond1 \
    --model mask_rcnn --eval-only

# 독립 평가 스크립트 (일괄)
python -m training.evaluate \
    --category Cable --experiment exp2 --condition all --model all
```

### 결과 리포트

```bash
# 비교 테이블 출력
python -m training.utils.report --experiment exp2

# CSV 내보내기
python -m training.utils.report --experiment exp2 --csv

# 특정 메트릭 기준
python -m training.utils.report --experiment exp3 --metric bbox_AP
```

### 결과 파일 위치

```
results/
├── merged_datasets/{exp}/{cond}/{cat}/     ← 병합 데이터 (images/ + annotations.json)
├── training/{exp}/{cond}/{cat}/{model}/    ← 체크포인트, 로그
│   ├── model_final.pth (detectron2) 또는 best_*.pth (mmdet)
│   ├── config.yaml / config.py
│   └── eval_results/results.json
├── evaluation/results.json                 ← 전체 결과 마스터 파일
└── reports/                                ← CSV, 비교 테이블
```
