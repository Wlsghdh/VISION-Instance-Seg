## 2. 실험 조건 브리핑

### 실험 1 (exp1): 생성AI 증강 수에 따른 성능 변화

**목적**: GenAI 이미지를 몇 장 추가해야 성능이 올라가는지 확인

> 원본은 모든 조건에서 **클래스당 20장** (`N_ORIGINAL_TRAIN_PER_CLASS=20`).
> Unified 모드: Cable 20 + Screw 20 + Casting 40 + Console 80 + Cylinder 80 + Wood 40 = **280장**

| 조건 | 원본 (클래스당) | GenAI/클래스 | Unified 합계 |
|------|:----:|:------------:|:------:|
| `baseline` | 20 | 0 | 280 |
| `genai_25` | 20 | 25 | ~629 |
| `genai_50` | 20 | 50 | ~978 |
| `genai_75` | 20 | 75 | ~1,326 |
| `genai_100` | 20 | 100 | ~1,675 |
| `genai_125` | 20 | 125 | ~2,024 |

**모델**: mask_rcnn, cascade_mask_rcnn

### 실험 2 (exp2): 전통 증강 vs 생성AI 비교

**목적**: 같은 양의 데이터를 전통 증강/GenAI로 만들었을 때 어느 쪽이 효과적인지

| 조건 | 원본 (클래스당) | GenAI/클래스 | 전통 증강 |
|------|:----:|:-----:|:--------:|
| `cond1` | 20 | 0 | 0 |
| `cond2` | 20 | 0 | 250 |
| `cond3` | 20 | 125 | 0 |
| `cond4` | 20 | 125 | 250 |
| `cond5` | 20 | 125 | 2,750 |

**모델**: mask_rcnn, cascade_mask_rcnn, maskdino

**데이터 부족 이슈**:
- cond5에서 전통증강 2,750장 요구 → Screw/Casting (250장뿐) 단일 카테고리 학습 시 부족
- Unified 모드에선 카테고리별로 가용량만큼 사용

### 실험 3 (exp3): 7종 모델 비교

**목적**: 동일 데이터로 7개 모델 성능 비교

| 조건 | 구성 | Cable | Screw | Casting |
|------|------|:-----:|:-----:|:-------:|
| `original_only` | 원본 클래스당 20장 | O (20/20) | O (20/20) | O (40/40) |
| `with_trad` | 원본 20/cls + 전통 3,000 | O (2750장<3000) | **X** (250장<3000) | **X** (250장<3000) |
| `with_genai_trad` | 원본 20/cls + GenAI 125/cls + 전통 2,750 | **X** (전통 부족) | **X** (전통 부족) | **X** (둘 다 부족) |

**모델**: mask_rcnn, cascade_mask_rcnn, maskdino, mask2former, cascade_rcnn, solov2, rtmdet_ins (7종)

**데이터 부족 이슈**:
- `with_trad`: Cable(2750장 있음, 3000 요구)부터 부족, Screw/Casting은 250장뿐
- `with_genai_trad`: 모든 카테고리에서 부족
- `original_only`만 전 카테고리 실행 가능

## 4. 실행 가능성 매트릭스

각 (실험 × 카테고리) 조합이 현재 데이터로 실행 가능한지:

| | Cable | Screw | Casting |
|---|:---:|:---:|:---:|
| **exp1 전체 조건** | 부분 (baseline~genai_100) | 전체 가능 | 부분 (baseline~genai_150) |
| **exp2 전체 조건** | 부분 (cond1~2) | 전체 가능 | 부분 (cond1~2) |
| **exp3 전체 조건** | 부분 (original_only) | 부분 (original_only) | 부분 (original_only) |

### 지금 바로 실행 가능한 조합

1. **Screw + exp2 전체 (cond1~5)** — 유일하게 모든 조건 충족
2. **3카테고리 × exp1 baseline~genai_100** — GenAI 100장 이내
3. **3카테고리 × exp2 cond1~2** — GenAI 불필요 (원본 + 전통만)
4. **3카테고리 × exp3 original_only** — 증강 불필요
