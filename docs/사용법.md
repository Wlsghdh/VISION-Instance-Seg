## 4. 데이터셋 병합 + 학습 (통합 환경)

> **⚠ Deprecated**: 옛 `scripts/data_utils/merge_dataset.py`는 더 이상 사용 안 함.
> 새 통합 환경 `training/`이 데이터 병합부터 학습/평가까지 한 번에 처리.
> 자세한 사용법: **[`docs/학습_guideline.md`](학습_guideline.md)** 참조.

### 4-1. 실험 조건 (config.py 정의)

> 모든 실험에서 원본 = **클래스당 20장** (`N_ORIGINAL_TRAIN_PER_CLASS=20`).
> Unified 모드: 6 카테고리 × 14 클래스 → 총 280장 원본.

**exp1 — GenAI 증강 수에 따른 성능 변화**

| 조건 | 원본 (클래스당) | GenAI/클래스 |
|---|:---:|:---:|
| baseline | 20 | 0 |
| genai_25 | 20 | 25 |
| genai_50 | 20 | 50 |
| genai_75 | 20 | 75 |
| genai_100 | 20 | 100 |
| genai_125 | 20 | 125 |

**exp2 — 전통 증강 vs GenAI 비교**

| 조건 | 원본 (클래스당) | GenAI/클래스 | 전통 증강 |
|---|:---:|:---:|:---:|
| cond1 | 20 | 0 | 0 |
| cond2 | 20 | 0 | 250 |
| cond3 | 20 | 125 | 0 |
| cond4 | 20 | 125 | 250 |
| cond5 | 20 | 125 | 2,750 |

**exp3 — 7종 모델 비교**: original_only / with_trad / with_genai_trad

### 4-2. 데이터 준비만 (학습 없이)

```bash
cd /project/ahnailab/{user}/VISION-Instance-Seg

# 단일 condition
python -m training.data_pipeline \
    --category Unified --experiment exp1 --condition baseline

# 모든 condition 일괄
python -m training.data_pipeline \
    --category Unified --experiment exp1 --condition all
```

출력: `results/merged_datasets/{exp}/{cond}/{cat}/seed{N}/{images/, annotations.json}`
- 시드별 분리 (`seed42/`, `seed43/`, ...)
- 원본 데이터에 **링크로 연결** → 디스크 데이터 1번만 존재
  - 우선순위: 하드 링크 → 심볼릭 링크 → 풀 카피 (fallback)
  - 같은 파일시스템: 하드 링크 / 다른 파일시스템: 심볼릭 링크

### 4-3. 학습 + 평가 (한 번에)

```bash
# 단일 시드 (기본 seed=42)
python -m training.train \
    --category Unified --experiment exp1 --condition baseline \
    --model cascade_mask_rcnn

# 모든 condition + 모든 모델 + 다중 시드 (정식 실험)
python -m training.train \
    --category Unified --experiment exp1 --condition all \
    --model all --multi-seed --skip-existing
```

학습 결과: `results/training/{exp}/{cond}/{cat}/{model}/seed{N}/`
- `model_best.pth` (Early stopping이 best 갱신 시점에 저장)
- `eval_results/results.json` (COCO 평가 결과)
- `cleanup_artifacts()`로 학습 부산물 자동 정리

자세한 옵션과 디렉토리 구조는 [`학습_guideline.md`](학습_guideline.md) 참조.
