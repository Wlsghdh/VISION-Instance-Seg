## 2. 대상 defect (3개)

## 6. 담당자 분배

### 1차 분배

| 담당 | GPU | 스크립트 | 실험 | N 범위 | 모델 | 학습 수 | 예상 시간 |
|------|:---:|---------|------|:------:|------|:------:|:---------:|
| **양진우** | 0 | `run_exp3_yjw.sh` | exp3 | N=1~4 | mask_rcnn, maskdino, mask2former | 36회 | ~9h |
| **주진호** | 1 | `run_exp3_jjh.sh` | exp2 + exp3 | Phase1 + N=5~7 | mask_rcnn, cascade_mask_rcnn, cascade_rcnn | 36회 | ~9h |
| **임대윤** | 3 | `run_exp3_ldy.sh` | exp3 | N=8~10 | solov2, rtmdet_ins | 18회 | ~6h |
| | | | | **1차 소계** | | **90회** | |

### 2차 분배 (1차 끝난 사람부터)

1차로 90회 완료 후, 남은 **138회**를 추가 분배합니다.
1차가 끝나면 알려주세요 → 2차 스크립트 생성하거나 아래처럼 수동 실행:

```bash
# 예: 양진우가 1차 끝나고 N=1~4 cascade_mask_rcnn 추가
CUDA_VISIBLE_DEVICES=0 conda run -n jjh python -m training.train \
  --category Inclusoes --experiment exp3 --condition trad_1x --model cascade_mask_rcnn \
  --max-epochs 200 --patience 10
```

### 미배정 조합 (2차용)

| N 범위 | 미배정 모델 |
|:------:|-----------|
| N=1~4 | cascade_mask_rcnn, cascade_rcnn, solov2, rtmdet_ins |
| N=5~7 | mask_rcnn, maskdino, mask2former, solov2, rtmdet_ins |
| N=8~10 | mask_rcnn, cascade_mask_rcnn, maskdino, mask2former, cascade_rcnn |

## 7. 실행 방법


### Step 2: tmux 세션 생성

```bash

```

### Step 3: 스크립트 실행

```bash
# 양진우 (GPU 0)
bash scripts/run_exp3_yjw.sh 0 Inclusoes Dirty impurities

bash scripts/run_exp3_jjh.sh 1 Inclusoes Dirty impurities

# 임대윤 (GPU 3)
```

**인자 설명:**
- 첫 번째: GPU 번호
- 두~네 번째: 3개 defect 이름

```
Ctrl+B → D
```

### Step 5: 상태 확인

```bash

tmux attach -t 본인이름

# 진행 상황 확인
grep "\[OK\]\|\[FAIL\]" results/logs/exp3_*.log | tail -20
```

## 8. defect 변경 시

다른 3개 defect로 바꾸고 싶으면 인자만 변경:

```bash
# 예: thunderbolt, Porosity, Dirty 로 변경
bash scripts/run_exp3_yjw.sh 0 thunderbolt Porosity Dirty
```

사용 가능한 개별 defect 이름:

| defect | 원본 카테고리 |
|--------|-------------|
| Inclusoes | Casting |
| Rechupe | Casting |
| Collision | Console |
| Dirty | Console |
| Gap | Console |
| Scratch | Console |
| Chip | Cylinder |
| PistonMiss | Cylinder |
| Porosity | Cylinder |
| RCS | Cylinder |
| impurities | Wood |
| pits | Wood |

Cable(thunderbolt), Screw(defect)는 원래 1클래스이므로 `--category Cable`, `--category Screw`로 사용.

## 10. 트러블슈팅

| 문제 | 해결 |
|------|------|
| CUDA OOM | 스크립트에 `--batch-size 8` 추가 |
| mmdet import 에러 | `conda activate jjh` 확인 |
| MaskDINO 에러 | `cd ~/gitrepo/MaskDINO/maskdino/modeling/pixel_decoder/ops && python setup.py build_ext --inplace` |
| 디스크 quota 부족 | `find results/training -name "model_*.pth" -not -name "model_final.pth" -delete` |
| 전통 증강 데이터 부족 | `python scripts/augmentation/traditional_augment.py` 실행 |
| 학습 중간에 멈춤 | tmux 재연결 후 실패 조건부터 수동 재실행 |
