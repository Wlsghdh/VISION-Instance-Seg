## CLI 기본 사용법

```bash
python -m training.train \
  --category Inclusoes \
  --experiment exp2 \
  --condition cond1 \
  --model mask_rcnn \
  --max-epochs 200 --patience 10
```

| 인자 | 설명 |
|------|------|
| `--category` | 카테고리 또는 개별 defect 이름 |
| `--experiment` | exp1, exp2, exp3 |
| `--condition` | 조건명 또는 `all` |
| `--model` | 모델명 또는 `all` |
| `--max-epochs` | 최대 에폭 (기본 200) |
| `--patience` | early stopping 횟수 (기본 10) |
| `--eval-only` | 평가만 실행 |

## 트러블슈팅

| 문제 | 해결 |
|------|------|
| CUDA OOM | `--batch-size 8` 또는 `4`로 줄이기 |
| mmdet import 에러 | `conda activate jjh` 확인 |
| MaskDINO 에러 | `cd ~/gitrepo/MaskDINO/maskdino/modeling/pixel_decoder/ops && python setup.py build_ext --inplace` |
| 디스크 quota | `find results/training -name "model_*.pth" -not -name "model_final.pth" -not -name "model_best.pth" -delete` |
| 전통 증강 부족 | `python scripts/augmentation/traditional_augment.py` |
| quota 자동 관리 | `quota_monitor.sh`가 30분마다 체크 + 80GB 초과 시 자동 정리 |
