## 3. 실험 2: 전통 증강 vs 생성AI 증강 비교

### 3-1. 목적
3가지 비교:
1. **Phase1**: 원본 vs 전통증강 vs GenAI — 어떤 증강이 효과적인가?
2. **Phase2**: (원본+GenAI) + 전통증강 N배 — 최적 증강량 탐색
3. **Phase3**: 최적 조건에서 7종 모델 비교

### 3-2. 대상
3개 defect만 선택 통합: `Exp2_3cls` (Inclusoes, Dirty, impurities)

### 3-3. 조건

**Phase 1 — 증강 방식 비교 (3조건)**

| 조건 | 원본 | GenAI/클래스 | 전통증강/클래스 |
|------|:----:|:-----------:|:--------------:|
| cond1 | 20 | 0 | 0 |
| cond2 | 20 | 0 | 125 |
| cond3 | 20 | 125 | 0 |

**Phase 2 — 전통증강 N배 탐색 (10조건)**

기본 단위 = 원본 20 + GenAI 125 = 145장/클래스

| cond4_4x | 580 | 725 |
| cond4_5x | 725 | 870 |
| cond4_6x | 870 | 1015 |
| cond4_7x | 1015 | 1160 |
| cond4_8x | 1160 | 1305 |

### 3-4. 모델

**Phase 1~2 (탐색용)**: 2종
- Mask R-CNN

**Phase 3 (비교용)**: 7종 전체

### 3-5. 규모

```
Phase 1:  3 조건 × 2 모델 = 6건

─────────────────────────────────
합계: 33건
```

**기존 계획(모든 조건 × 7모델 = 91건) 대비 64% 감소**

## 5. 스크립트 수정 사항 (2026-04-14)

### 5-1. 변경 이유

**기존 문제**:
- `cond4_1x~10x × 7모델 × 3명 = 70건` 전부 실행 → GPU 자원 낭비
- 원래 실험 설계는 **2모델로 최적 N 탐색 → 그 조건만 7모델 비교**였음

**수정 내용**:
- `run_exp2_jjh.sh`: Phase2를 7모델 → **2모델로 축소**, skip 로직 추가, 쿨다운 5분 → 30초
- `run_exp2_yjw.sh`: 7모델 → **2모델로 축소**
- `run_exp2_ldy.sh`: 7모델 → **2모델로 축소**
- `run_exp2_phase3.sh`: **신규 생성**, 최적 N배 × 7모델 비교용

### 5-2. 이전 실행 중 수정한 코드

| 파일 | 수정 내용 |
|------|----------|
| `training/adapters/mmdet_adapter.py` | SOLOv2 bbox 평가 에러 수정 (mask-only 분기) |
| `training/adapters/detectron2_adapter.py` | MaskDINO/Mask2Former OOM 방지 (batch=2, AMP, max_size=800) |
| `training/adapters/detectron2_adapter.py` | `output_dir` Path 변환 버그 수정 |

## 6. 하이퍼파라미터 (통일)

`training/config.py`의 `DEFAULT_HYPERPARAMS`. 모든 실험에 동일 적용.

| 파라미터 | 값 | 비고 |
|---------|-----|------|
| lr | 0.0015 | Linear Scaling Rule + fine-tuning 보정 |
| batch_size | 12 | A100 80GB 활용률 개선 |
| max_epochs | 1000 (exp1) / 200 (exp2) | early stopping으로 자동 종료 |
| warmup_epochs | 5 | |
| eval_period_epochs | 5 | |
| early_stopping_patience | 15 (exp1) / 10 (exp2) | |
| input_min_size | (640, 672, 704, 736, 768, 800) | detectron2 기본값 |
| input_max_size | 1333 | 고해상도 유지 |
| seed | 42 | 단일 시드 (다중 시드 미사용) |

**예외**: MaskDINO / Mask2Former
- batch_size 2로 자동 축소
- AMP (mixed precision) 활성화
- input_max_size 800으로 축소
- 메모리 제약 때문에 어댑터에서 자동 처리

## 7. 평가 지표

| 레벨 | 지표 | 계산 |
|------|------|------|
